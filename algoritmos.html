Algoritmos: cómo piensa un ordenador

Qué es un algoritmo, explicado con ejercicios, y una simulación para ver por dentro cómo un ordenador guarda tus instrucciones y las ejecuta una a una.

  • Ir a la simulación
  • Empezar por el principio

1¿Qué es un algoritmo?

Un algoritmo es una lista de pasos, en un orden concreto, que resuelve un problema o realiza una tarea. Lo usas cada día: una receta, las instrucciones de un mueble o el camino al instituto son algoritmos.

Para que un ordenador pueda seguirlo, un algoritmo tiene que cumplir tres condiciones:

Preciso

Cada paso dice exactamente qué hacer. «Echa un poco de sal» no vale: ¿cuánto es un poco?

Ordenado

Los pasos van en una secuencia. Si cambias el orden, el resultado cambia (o no funciona).

Finito

Tiene que terminar. Un algoritmo que se repite para siempre nunca da un resultado.

2Dibujar un algoritmo: el diagrama de flujo

Los algoritmos se pueden dibujar. En un diagrama de flujo cada forma tiene un significado: el óvalo es el inicio o el fin, el rectángulo es una acción y el rombo es una pregunta que solo puede responderse con Sí o No. Las flechas indican el orden.

Fíjate en que algunas flechas vuelven hacia atrás: eso es un bucle, una parte que se repite hasta que se cumple una condición.

3Simulación: así ejecuta un ordenador tu algoritmo

Un ordenador no entiende frases. Tu algoritmo se escribe con instrucciones muy simples, se traduce a código máquina (ceros y unos), se guarda en la memoria, y la CPU lo ejecuta repitiendo siempre el mismo ciclo para cada instrucción:

① CaptarLa CPU lee de la memoria la instrucción que indica el contador de programa.
② DecodificarLa unidad de control traduce los ceros y unos a una orden: «avanzar», «girar»…
③ EjecutarSe realiza la orden (el robot se mueve) y el contador pasa a la siguiente instrucción.

    4En resumen

    AlgoritmoLista de pasos precisa, ordenada y finita para resolver un problema.
    ProgramaEl algoritmo escrito en un lenguaje que el ordenador puede traducir.
    Código máquinaEl programa convertido en ceros y unos y guardado en la memoria.
    CPUCapta, decodifica y ejecuta cada instrucción, una tras otra, sin pensar.

    La idea más importante: el ordenador hace exactamente lo que dice el programa, ni más ni menos. Si el robot choca, no es culpa del ordenador; es que el algoritmo tenía un error.

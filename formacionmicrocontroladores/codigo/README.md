# Código de partida

Esqueletos de los proyectos de la fase 1. Tienen la estructura (pines, constantes, estados y funciones vacías), **no la solución**: cada `TODO` es trabajo tuyo.

| Carpeta | Proyecto |
| --- | --- |
| `P01_semaforo` | P1 · Semáforo con pulsador de peatones |
| `P02_luz_nocturna` | P2 · Luz nocturna automática |
| `P03_termometro` | P3 · Termómetro con pantalla |
| `P04_simon` | P4 · Juego de reflejos tipo Simón |

Cómo usarlos:

1. Copia la carpeta a tu propio repositorio de proyectos (el nombre de la carpeta y del `.ino` deben coincidir, es una regla del IDE de Arduino).
2. Ábrela con Arduino IDE 2.
3. Ajusta los pines a tu esquema y completa los `TODO` en orden.

A partir de la fase 3 los proyectos se organizan con PlatformIO y ya no hay esqueletos: el diseño del código también es parte del trabajo.

# Guitarra

Mástiles interactivos para estudiar guitarra.

- `index.html`: portada
- `triadas.html`: triadas mayores y menores en los cuatro grupos de cuerdas
- `arpegios.html`: arpegios de triadas y de séptima en las cinco formas

Son páginas estáticas, sin dependencias, así que se pueden publicar con GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
